## 🚀 Getting Started

### Prerequisites
- macOS 14.0 or later
- Xcode 15.0 or later
- iOS 17.0+ deployment target
- Apple Developer Account (for App Store deployment)

### Installation

1. **Clone the repository**
   ```bash
   cd ui/ios/InventoryManagement
   ```

2. **Open in Xcode**
   ```bash
   open InventoryManagement.xcodeproj
   ```

3. **Build and Run**
   - Select your target device (iPhone/iPad simulator or physical device)
   - Press `Cmd + R` to build and run
   - Or click the "Play" button in Xcode
